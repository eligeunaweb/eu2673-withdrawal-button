# EU2673 Withdrawal Button

Open-source WooCommerce plugin that provides a clear withdrawal mechanism for customers, including registered users and guest orders.

**Current source package:** 1.1.2  
**Author:** Álvaro Martínez — AdaptaTuWeb.com  
**License:** GPL-2.0-or-later

## Features

- Withdrawal button on WooCommerce order details and thank-you pages
- Confirmation modal with legal text
- Customer acknowledgement and administrator notification emails
- Status update emails
- Withdrawal request management with filters and CSV export
- Configurable automatic order status changes
- Guest checkout support
- Public withdrawal form via `[eu2673_withdrawal_form]`
- Product-level withdrawal status: standard, excluded, or digital consent
- Digital-content consent for digital/downloadable products
- Product and category exclusions
- Configurable withdrawal period with optional grace days
- 16 bundled translations
- WooCommerce HPOS compatibility declaration

## Requirements

- WordPress 5.8+
- WooCommerce 6.0+
- PHP 7.4+

## Installation

1. Install the plugin from the official WordPress.org directory, or upload the plugin folder to `/wp-content/plugins/eu2673-withdrawal-button/`.
2. Activate **EU2673 Withdrawal Button** in WordPress.
3. Make sure WooCommerce is active.
4. Open **Withdrawal → Settings** to configure the plugin.
5. Optionally create a public withdrawal page using `[eu2673_withdrawal_form]`.
